# Version 0.2 released

The ngscopeclient team is excited to announce the release of version 0.2.

This release includes a few new drivers and filters, but is primarily focused on performance, stability, and improving the internal application architecture to be more maintainable in the future. It introduces GPU acceleration for many additional filters, offering massive (1-3 order of magnitude) speedups on common operations.

By the numbers:
* 92 all-time contributors to the codebase, 8 new contributors since v0.1.1
* Supports instruments from 28 vendors, 6 new drivers since v0.1.1
* 204 filter graph blocks, 6 new since v0.1.1
* 1611 commits since v0.1.1

* [Download binaries on GitHub](https://github.com/ngscopeclient/scopehal-apps/releases/tag/v0.2)
* [Download binaries from our artifact server](https://dl1.ngscopeclient.org/ngscopeclient-releases/v0.2/)
