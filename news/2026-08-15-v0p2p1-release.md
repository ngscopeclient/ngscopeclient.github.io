# Version 0.2.1 released

The ngscopeclient team is excited to announce the release of version 0.2.1.

This is a hotfix release for v0.2 that addresses a race condition in the PicoScope and ThunderScope drivers leading to GPU memory leaks and out-of-memory crashes if a new waveform arrives before driver processing of the previous waveform has finished, as well as a few other minor bugs.

There are no new features in this release.

Please see the [v0.2 release notes](/news/2026-08-13-v0p2-release.html) for a list of changes since version 0.1.1.
