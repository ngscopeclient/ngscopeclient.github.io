# Version 0.2.2 released

The ngscopeclient team is excited to announce the release of version 0.2.2.

This is a hotfix release for v0.2.1 that fixes a MacOS packaging issue as well as an incorrect coefficient in the third tap of the Blackman-Harris window function.

There are no new features in this release.

Please see the [v0.2 release notes](/news/2026-08-13-v0p2-release.html) for a list of other changes since version 0.1.1.

* [Download binaries on GitHub](https://github.com/ngscopeclient/scopehal-apps/releases/tag/v0.2.2)
* [Download binaries from our artifact server](https://dl1.ngscopeclient.org/ngscopeclient-releases/v0.2.2/)
