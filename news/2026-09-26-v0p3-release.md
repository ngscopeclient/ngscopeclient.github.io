# Version 0.3 released

The ngscopeclient team is excited to announce the release of version 0.3.

This is a relatively small update with several bug fixes and performance improvements and would normally have been named v0.2.3, but since it breaks compatibility with very old ThunderScope (TS.NET versions prior to 0.1 release) software we decided to bump the minor version number instead.

Quick summary of new features (see [the release notes](https://github.com/ngscopeclient/scopehal-apps/blob/master/release-notes/v0.3.md) for full details):

* Preliminary driver for Keysight Infiniium oscilloscopes. Not anywhere near feature complete but basic channel controls and waveform capture should work.
* ThunderScope now has native auto-trigger support with faster update rate
* Early light-mode color theme support. There are probably still rough edges in light mode; please open tickets if you find any parts of the UI that are not readable / functional in light mode.
* Many speed improvements to the protocol analyzer subsystem when working with huge numbers of packets
* Ethernet FCS calculation is now GPU accelerated for the 100baseT1 decoder, other Ethernet decodes still use CPU-based CRC and will follow in a future release
